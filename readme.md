# Mini Project Hub

![Mini Project Hub 썸네일](public/images/mini-project-hub-site-codex.svg)

## 프로젝트 소개
Mini Project Hub는 여러 미니 프로젝트 저장소의 핵심 정보를 한 화면에서 확인할 수 있도록 만든 허브 사이트입니다.  
카드 목록에서 프로젝트를 빠르게 탐색하고, 상세 화면에서 README/커밋/PR 활동 요약을 함께 확인할 수 있도록 구성되어 있습니다.

## 이 프로젝트의 역할
- **프로젝트 허브 역할**: 여러 저장소를 한 곳에서 탐색할 수 있는 진입점 제공
- **상태 가시화 역할**: 커밋/PR/최근 활동 데이터를 통해 프로젝트 진행 상황을 직관적으로 노출
- **운영 자동화 역할**: GitHub Actions 기반 캐시 데이터 파이프라인으로 데이터 갱신 자동화
- **협업 기준점 역할**: 프로젝트 데이터 구조/검증 규칙/기여 절차 문서화를 통해 일관된 운영 지원
