# 작업 이력 (한글)

이 문서는 저장소의 주요 변경 사항을 한글로 요약해 관리합니다.  
원본 커밋 메시지가 영어인 경우에도 이해하기 쉽도록 한국어로 재정리했습니다.

## 최근 작업 흐름 요약

### 1) 상세 화면 고도화
- 상세 페이지의 요약 정보/레이아웃을 개선하고 README 렌더링 품질을 높였습니다.
- 카드에서 상세 페이지로 이동하는 흐름과 버튼 배치를 정리해 사용성을 개선했습니다.

### 2) 프로젝트 상세 기능 확장
- 프로젝트 상세 화면을 도입하고, README와 활동 차트를 함께 보여주도록 기능을 확장했습니다.
- 저장소별 최신 상태를 카드와 상세 화면에서 더 쉽게 파악할 수 있게 했습니다.

### 3) 데이터 수집/캐시 파이프라인 강화
- GitHub Actions 기반으로 프로젝트 데이터를 정적 JSON으로 생성/배포하는 파이프라인을 구축했습니다.
- ETag 재사용 최적화를 적용해 불필요한 API 호출을 줄이고 캐시 효율을 높였습니다.
- 최근 활동 커밋 집계를 페이지네이션 방식으로 개선해 데이터 신뢰도를 높였습니다.
- 오픈 PR 집계 로직을 보완해 전체 개수를 정확하게 반영하도록 수정했습니다.

### 4) 썸네일 및 목록 운영 개선
- 허브 프로젝트 전용 썸네일을 추가하고, 썸네일 fallback 처리 문제를 수정했습니다.
- 신규 프로젝트 항목(예: mini-delivery-log-report-system)을 목록에 반영했습니다.

## 작업 이력 업데이트 원칙
- 신규 기능/수정/운영 변경이 머지되면 이 문서에 한글 요약을 추가합니다.
- 중복 나열보다 “무엇이 왜 바뀌었는지”를 중심으로 간단 명확하게 기록합니다.
- 필요 시 관련 문서(`CONTRIBUTING.md`, `docs/data-schema.md`) 링크를 함께 남깁니다.
